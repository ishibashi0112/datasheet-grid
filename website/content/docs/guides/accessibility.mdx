グリッドは WAI-ARIA の [grid パターン](https://www.w3.org/WAI/ARIA/apg/patterns/grid/) に沿って作っています。キーボードだけで操作でき、アクティブセルを動かすとスクリーンリーダーがそのセルを読み上げます。このページでは、何をグリッドがしていて、何をアプリの側で足すとよいかをまとめます。

## キーボード

- **`Tab` 1 回で出入りします。** グリッドの中のボタン(列見出しの `⋮`、グループ行の開閉、展開のトグル)は `Tab` の順番に入れず、グリッドの中は矢印キーで動きます。最終列の `Tab` / 先頭列の `Shift+Tab` でグリッドの外の次 / 前の要素へ出ます。
- **見出しの操作**: アクティブセルで `Alt+↓`(Mac は `Option+↓`)を押すと、その列の列メニューが開きます。並べ替え・フィルター・列の固定・幅の自動調整・列の表示はここから使えます。
- **右クリックメニュー**: アクティブセルで `Shift+F10` / メニューキー(Windows のアプリケーションキー)を押すと、そのセルの右クリックメニュー(`enableContextMenu`)が開きます(1.1.0 から)。
- **開閉**: グループ行と展開行のトグルは、アクティブセルで `Enter` / `Space` です。
- **ポップオーバーとメニュー**: 列メニューと右クリックメニューは、マウスで開いてもキーで開いてもメニューへフォーカスが移り、矢印キーで項目を移って `Escape` / `Tab` で閉じます。列フィルターのポップオーバーとツールパネルは `Tab` が中で回り、`Escape` で閉じると、列フィルターはグリッドへ、ツールパネルは開いた部品(上部バーの絞り込みの要約など)へフォーカスが戻ります。
- **フォーカスの位置**: フォーカスはアクティブセルの枠で示します。`Tab` で入った直後などアクティブセルが無いときは、表の内側にアクセント色(`--ssg-accent`)の枠を出します(マウスで触った後は出しません)。
- **ページのスクロール**: キーボードでアクティブセルを動かすと、グリッドを囲むスクロールする親やページも最小限スクロールして、アクティブセルを画面に入れます。

キーの一覧は [キーボード / タッチ操作](/docs/guides/keyboard) にあります。

### ポインタでしかできない操作

次の操作はマウス / タッチでだけ行えます。キーボードだけで使う利用者にも要る操作なら、アプリのボタンから同じことができるようにしてください。

| ポインタの操作 | キーボードやアプリのボタンで代わりにできること |
| --- | --- |
| 行番号の右クリックメニュー(`target.type` が `'rowHeader'`) | キーで開くのはアクティブセルのメニュー(`target.type: 'cell'`)だけなので、行の操作はセルのメニューかアプリのボタンにも置く |
| 列幅のドラッグ | 列メニューの「この列の幅を自動調整」。決まった幅にするときはアプリのボタンから `applyState({ columnWidths })` |
| 列の並べ替えのドラッグ | `onColumnsChange` で持っている `columns` の並びを、アプリのボタンで入れ替える |
| 行のドラッグ(`enableRowDrag`) | ハンドルの `moveRow` を呼ぶボタン |
| フィルハンドル(`fillHandle`) | コピー(`Ctrl/Cmd+C`)と貼り付け(`Ctrl/Cmd+V`) |

## スクリーンリーダー

- **表の名前**: `ariaLabel` で表に名前を付けます。1 画面に複数のグリッドを置くときは必ず付けてください。

  ```tsx
  <SpreadsheetGrid ariaLabel="受注一覧" rows={rows} columns={columns} />
  ```

- **セルの読み上げ**: フォーカスを受ける要素の `aria-activedescendant` がアクティブセルを指すので、矢印キーで動くたびに支援技術がそのセルを読み上げます。仮想化で描いていない行・列は DOM に無いため、表全体の中の位置は `aria-rowindex` / `aria-colindex` / `aria-rowcount` / `aria-colcount` で伝えます。
- **メニューとパネル**: 列メニューは `role="menu"`(名前は列名)で、項目は `menuitem`、並べ替えの昇順 / 降順と「列の固定」の項目は `menuitemradio` + `aria-checked` です。列見出しの `⋮` は `aria-haspopup="menu"` / `aria-expanded` を持ちます。ツールパネルと列フィルターのポップオーバーは名前の付いた `role="dialog"`(モーダルではない)です(列メニューとツールパネルの役割は 1.1.0 から)。
- **状態**: 選択範囲のセルは `aria-selected`、編集できないセルは `aria-readonly`、並べ替えの第 1 キーの列見出しは `aria-sort`、読み込み中の行(serverSide)は `aria-busy` です。
- **検査とメモ**: 検査に通らないセルは `aria-invalid` で、メッセージとメモ(`cellNote`)は `aria-description` で伝えます(ツールチップと同じ文)。`'reject'` の列で確定できないときのメッセージは `role="alert"` です([入力の検査](/docs/guides/validation))。
- **エディタ**: 編集中のエディタは「`数量 を編集`」のような名前を持ち、編集中のセルの中にあるものとして伝わります(`aria-owns`)。select エディタは combobox と listbox です。
- **ボタンの名前**: 列見出しの `⋮`(「`数量 の列メニュー`」)、行のチェックボックス(「行 3 を選択」)、グループの開閉(「`東京 を展開`」)など、グリッドが出すボタンにはすべて読み上げの名前があります。英語の画面では [英語と文言](/docs/guides/localization) の `localeTextEn` を渡すと、読み上げの名前も英語になります。

要素ごとの役割と属性の一覧は [SpreadsheetGrid props の「アクセシビリティ」](/docs/api/props#アクセシビリティ) にあります。

## 見た目

- **動きを減らす**: 既定の `motion="auto"` は、OS / ブラウザの「視差効果を減らす」(`prefers-reduced-motion: reduce`)が有効ならアニメーションを止めます。いつも止めるときは `motion="off"` です([モーション](/docs/guides/motion))。
- **ハイコントラスト**: Windows のハイコントラストなど、ブラウザが色をシステムの色に置き換える環境(`forced-colors: active`)では、色だけで伝えていた部分(検査に通らないセル、メモの印、条件付き書式のチップ)を枠や記号で描きます([テーマ](/docs/guides/theming#ハイコントラストforced-colors))。
- **コントラスト**: 既定の色のうち、ツールパネルなどの補足の文字と条件付き書式のチップの `critical` は、WCAG AA の 4.5:1 に届きません。基準に合わせるときに上書きするトークンの値を [テーマ の「コントラストを上げる」](/docs/guides/theming#コントラストを上げる) に載せています。
- **行の高さと余白**: 行の高さと余白は `density`(`'compact'` / `'standard'` / `'comfortable'`)と `rowHeight` で変えられます。押しやすさを優先する画面では広めにします。

## アプリの側で気をつけること

- **`renderCell` で置くボタンやリンク**には、見えている文字か `aria-label` で名前を付けます。グリッドはその中身を知りません。なお、セルに置いたボタンは最終列の `Tab` では止まらないので、キーボードで押す必要があるなら、行の操作を展開行のカードやアプリのボタンにも置きます。
- **自作のエディタ**(`editor: { type: 'custom' }`)の入力欄には、組み込みのエディタと同じく名前を付けます(``aria-label={`${title} を編集`}`` など)。
- **色だけで意味を伝えない**: `cellClassName` / `getRowClassName` で色を付けて状態を示すときは、文字や記号も添えます(条件付き書式の `chips` は既定で記号を出します)。
- **ダイアログの中のグリッド**: グリッドのポップアップ(列メニュー・フィルター・select の候補など)は、既定でグリッドを囲むダイアログの中に出るので、モーダルがフォーカスを中に閉じ込めていても使えます(1.1.0 から。場所は `popupContainer` で変えられます。[ダイアログの中で使う](/docs/guides/dialogs))。グリッドが使う `Escape`(編集の取り消しなど)ではダイアログは閉じず、もう一度押すと閉じます([キーボード / タッチ操作](/docs/guides/keyboard#ダイアログの中のグリッド))。

## 分かっている制限

- 固定列(`pinned`)があると、1 つの行が左 / 中央 / 右のペインごとの行(`role="row"`)に分かれます。どれも同じ `aria-rowindex` を持ちますが、読み上げの順はペインごとです。
- 展開行(`detailRow`)の帯は `aria-rowindex` を持ちません(データ行の番号をずらさないため)。縦に固定したラベル行(`labelRow.sticky`)の複製は `aria-hidden` で、本物のラベル行が読み上げられます。
- 編集中は、axe などの検査ツールが表に `aria-required-children` を出すことがあります。エディタは行の外に描いて編集中のセルから `aria-owns` でつないでおり、ブラウザのアクセシビリティツリーではセルの子です(Chrome で確認)が、検査ツールは `aria-owns` で移した要素を元の親の子としても数えるためです。
