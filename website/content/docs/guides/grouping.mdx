`column.rowGroup: true` の列でビュー行をグルーピングします(複数指定時は `columns` 配列の出現順が階層順)。`aggFunc` を指定した列は、グループ行に集計値を表示します。

## デモ(地域 > 担当 の 2 階層)

<GroupingDemo />

- グループ行のシェブロン(またはダブルクリック / Enter / Space)で開閉できます。グループ行のセルを押すとアクティブセルになるので、押してから Enter / Space でも開閉できます。
- **数量 / 金額**列は `aggFunc: 'sum'` の集計値です。`valueFormatter` は集計値にも適用され、leaf セルと表示が揃います。
- 「すべて展開 / 折りたたむ」は命令的ハンドルの `expandAllGroups()` / `collapseAllGroups()` です。
- 列の ⋮ の「この列でグループ化」で、その列を階層の一番下に足します(商品の ⋮ で地域 > 担当 > 商品)。グルーピング中は「グループ化を外す」ですべての階層を外せます。どちらも `onColumnsChange` で列定義を受け取っている表だけです。
- 金額の ⋮ の「降順で並び替え」で、グループも合計の大きい順に並びます。
- 上部バーの「絞り込み」を押し、「+ フィルターを追加…」で「地域(グループ化中)」を選ぶと、自動グループ列の見出しの下に地域のフィルターが開きます(グループ元の列は表示から外れていても絞り込めます)。

## 列定義

```tsx
const columns: GridColumn<Row>[] = [
  { key: 'region', title: '地域', width: 100, rowGroup: true },
  { key: 'rep', title: '担当', width: 100, rowGroup: true },
  { key: 'product', title: '商品', width: 170 },
  { key: 'qty', title: '数量', width: 100, aggFunc: 'sum' },
  { key: 'amount', title: '金額', width: 140, aggFunc: 'sum',
    valueFormatter: numberFormatter() },
]
```

## 仕様の要点

- **自動グループ列** — グルーピング有効時、先頭にツリー表示列(インデント + 開閉 + ラベル + 件数)が自動注入され、グループ元列は表示から外れます。
- **組み込み集計** — `'sum' | 'min' | 'max' | 'avg' | 'count'`。数値化できる値のみ対象で、空値は除外されます(`count` は配下 leaf 行数)。カスタム集計は関数(`GridAggFunc<T>`)を渡します。
- **集計値の表示** — 合計行と同じ書式です。列の `valueFormatter` があれば集計値にも適用し、無ければ数値は桁区切り + 小数 4 桁まで(カスタム集計の数値も同じ。文字列はそのまま)。合計以外(平均 / 最小 / 最大 / 個数)は値の前に種類を小さく出します(`平均 4,115.33`)。
- **フィルター / ソートとの関係** — フィルターは leaf 行に適用され、0 件になったグループは消えます。グループの並びは「ソート適用後の初出順」です。集計のある列(`aggFunc`)で並べ替えると、グループもその集計値の順に並びます(金額の降順なら合計の大きいグループが上。並べ替えの条件にその階層のグループ元の列が先にあれば、その列の順)。グループ元列は表示から外れますが、そのソートと列フィルターは効きます(グループ元列でソートするとグループごと並び替わります。「並び替えを管理…」パネルの候補にグループ元列が入ります。グループ元列の絞り込みは、フィルターの管理パネルの「+ フィルターを追加…」から「地域(グループ化中)」のように選ぶと自動グループ列の見出しの下に開き、掛けたものは管理パネルとチップバーに「(グループ化中)」として出ます)。グローバルフィルターはグループ元列の値も探します。ツールパネルの「列」タブではグループ元列を「(グループ化中)」として出し、表示 / 非表示は切り替えられません(ドラッグで並べ替えると階層の順番も入れ替わります)。
- **leaf 限定の各機能** — グループ行は編集 / コピー / 行選択 / エクスポートの対象外です(すべて leaf 行が対象)。エクスポートは開閉状態に関わらず、フィルター / ソート後の leaf 行をすべて出力します(折りたたんだグループの配下も含みます)。
- **clientSide 限定** — serverSide(`dataSource`)では `rowGroup` は無視されます。

## エクスポート(CSV / TSV / Excel)

グルーピング中の `exportCsv` / `downloadCsv` / `getExportData` は、表示から外れているグループ元の列を先頭に入れます。どの行にもグループの値が入った平らな表になるので、Excel のピボットや読み込み直しにそのまま使えます。`includeGroupRows: true` を渡すと、各グループの先頭に小計の行(集計のある列にそのグループの集計値)も入ります(帳票向け。scope `'view'` のときだけ)。

```tsx
gridRef.current?.exportCsv();
// 地域,区分,担当,金額
// 関東,法人,佐藤,100
// 関東,個人,鈴木,200

gridRef.current?.exportCsv({ includeGroupRows: true });
// 地域,区分,担当,金額
// 関東 小計,,,300
// 関東,法人 小計,,100
// 関東,法人,佐藤,100
// 関東,個人 小計,,200
// 関東,個人,鈴木,200
```

`getExportData({ includeGroupRows: true })` では `rowKinds` の `'group'` で小計の行を見分けられます(Excel 側で太字にするなど)。集計値は生値(数値のまま)です。`isRowExportable` で出力から除いた行は小計にも数えず、行が 1 つも残らないグループは小計の行も出しません。

開閉の命令的 API(`setGroupCollapsed` / `getGroupRows` など)は [API リファレンス](/docs/api/handle#行グルーピング) を参照してください。
