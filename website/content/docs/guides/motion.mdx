---
title: モーション
description: アニメーション / トランジションの有効化(motion prop)と CSS トークンによる調整
---

グリッドの動き(アクティブセル枠の追従、ポップオーバーの出現、ソート時の行移動、読み込み中のシマー等)は `motion` prop で一括制御します。既定は `'auto'` で、OS / ブラウザの「視差効果を減らす」設定を尊重します。

```tsx
<SpreadsheetGrid motion="auto" ... />  // 'auto'(既定) | 'on' | 'off'
```

| 値 | 挙動 |
| --- | --- |
| `'auto'` | `prefers-reduced-motion: reduce` が有効なら `'off'`、それ以外は `'on'`。設定の変化にも追従します。 |
| `'on'` | OS 設定に関わらず動かします。 |
| `'off'` | すべて止めます(表示結果は同じで、瞬時に切り替わります)。 |

## 効果の一覧

| 効果 | 既定 | トークン | 備考 |
| --- | --- | --- | --- |
| アクティブセル枠 / 選択範囲の追従 | 有効 | `--ssg-motion-fast` | キーボード移動 / クリックで枠が新しい位置へ滑ります。スクロール中とポインタでの範囲ドラッグ中は瞬時に追従します。 |
| ポップオーバー / メニューの出現 | 有効 | `--ssg-motion-fast` | 列メニュー / コンテキストメニュー / フィルター / ツールパネル / select 候補 / 日付パネルが 4px 上からフェードインします(出現のみ)。 |
| 読み込み中のシマーと到着行のフェードイン | 有効 | `--ssg-motion-base` | SSRM の取得中はスケルトンに光の帯が流れ、到着した行のセルが上から順に 3px 下からフェードインします。スクロールで出入りする行は対象外です。 |
| 細かな遷移 | 有効 | `--ssg-motion-fast` | ヘッダー操作アイコンのフェード、チェックボックス、タブのインジケータ、ツールチップ、スクロール位置インジケーター。 |

## 速さの調整(CSS トークン)

各効果は 3 つの継続時間トークンとイージングだけを参照します。利用側は `.ssg-root` へのトークン上書きで一括調整できます。

```css
.ssg-root {
  --ssg-motion-fast: 100ms;   /* 既定 140ms: アクティブセル枠の追従、ポップオーバーの出現 */
  --ssg-motion-base: 200ms;   /* 既定 260ms: 行の移動、開閉 */
  --ssg-motion-slow: 450ms;   /* 既定 600ms: 変更セルのフラッシュ等の一過性の強調 */
  --ssg-motion-ease: ease-out; /* 既定 cubic-bezier(0.2, 0.8, 0.2, 1) */
}
```

`'off'`(または `'auto'` + 視差効果を減らす)のときは、グリッド本体とポップオーバー / メニュー / パネル / ドラッグゴースト / ツールチップに `.ssg-motion-off` が付き、継続時間トークンが 0 になります。`:where`(特異度 0)で定義しているため、停止中でも特定の効果だけ戻すことができます。

```css
/* 停止中でもアクティブセル枠の追従だけは動かす */
.ssg-root.ssg-motion-off {
  --ssg-motion-fast: 140ms;
}
```

## 注意

- SSR(Next.js 等)では `'auto'` はいったん `'on'` で描画し、ハイドレーション後にクライアント側で再解決します(`theme='auto'` と同じ)。
- `prefers-reduced-motion` を直接見ていた従来の効果(ツールパネルのフラッシュ、フィルター候補のスピナー、スクロール位置インジケーターのフェード)も `motion` の実効値で判定します。`'auto'` では従来と同じ挙動です。
