---

`fillHandle` prop を渡すと、選択範囲(無ければアクティブセル)の右下に小さな四角(**フィルハンドル**)が出ます。引くと Excel のオートフィルと同じく、元の値の続き(**連続データ**)か元の値の繰り返し(**セルのコピー**)で埋めます。既定では無効の opt-in 機能です。

## デモ(生産計画 > ロット・日付・曜日を引いて埋める)

<FillHandleDemo />

- 「ロット」の 2 行を選んで四角を下へ引くと `LOT-003`, `LOT-004` … と続きます。「日付」「曜日」は 1 つからでも 1 日ずつ進みます。
- 「工程」の 3 行を引くと 切削 → 研磨 → 検査 の繰り返し(コピー)になります。
- 「数量」の 2 行(50, 100)を引くと 150, 200 … と等差で続きます。1000 を超える値は `validate`(reject)で書かれません。
- 「担当」列は編集不可のため、範囲に入っていても書き換わりません。
- 引いている間は埋める範囲が点線で、いちばん遠いセルへ入る値がポインタの近くに出ます。`Ctrl`(Mac は `⌘`)を押すと連続データとコピーが入れ替わり、`Escape` でやめます。
- 離すと右下にボタンが出ます。押して「連続データ / セルのコピー」を選び直せます。元に戻すは 1 回で埋める前へ戻ります。
- 四角をダブルクリックすると、左隣の列に値が続くところまで下へ埋めます。

## 使い方

```tsx
<SpreadsheetGrid rows={rows} onRowsChange={setRows} columns={columns} fillHandle />
```

書き込み先が要ります。clientSide は `onRowsChange`、serverSide は `dataSource.updateRows` が無いとハンドルは出ません。`readOnly` のときも出ません。

### 埋める値を差し替える

`fillHandle` にオブジェクトを渡すと、`getFillValue` で埋めるセルごとに書く値を決められます。既定のままにするセルは `defaultValue` を返してください。

```tsx
fillHandle={{
  getFillValue: ({ column, defaultValue, sourceValues, index, direction, kind }) => {
    // 数量列は 10 の倍数に丸める
    if (column.key === 'qty' && typeof defaultValue === 'number') {
      return Math.round(defaultValue / 10) * 10;
    }
    return defaultValue;
  },
}}
```

| 引数 | 説明 |
| --- | --- |
| `column` / `row` / `rowIndex` | 埋めるセルの列 / 行(書き込み前)/ ビュー行 index。 |
| `sourceValues` | 元の値。埋める向きの順で、最後の要素が埋めるセルに一番近い。 |
| `index` | 元の範囲の直後を 0 とする位置(ラベル行 / グループ行は数えない)。 |
| `direction` | `'down' \| 'up' \| 'right' \| 'left'` |
| `kind` | この列 / 行の埋め方(`'series' \| 'copy'`)。 |
| `defaultValue` | 既定で書く値。 |

`getFillValue` は編集できないセルでは呼ばれません。ドラッグ中のツールチップ(いちばん遠いセルの値)を出すときにも呼ぶため、副作用の無い関数にしてください。返した値も `validate` を通り、`validationMode: 'reject'` で不正なら書きません。

## 埋め方の決まり方

列ごと(上下へ引いたとき)/ 行ごと(左右へ引いたとき)に決めます。続き方の分かる値は連続データ、数値 1 つ・数字だけの文字列 1 つ・続き方の無い値はコピーです。`Ctrl` / `⌘` を押しながら引くとこれが入れ替わります(数値 1 つなら 1 ずつ増える)。

| 元の値 | 既定 | 連続データの続き |
| --- | --- | --- |
| `1` | コピー | `2, 3, 4 …`(`Ctrl` / `⌘`) |
| `1, 3` | 連続データ | `5, 7, 9 …`(2 つ以上は最小二乗の直線) |
| `2026-11-02` | 連続データ | `2026-11-03, 2026-11-04 …`(形式を保つ) |
| `2026-01-15, 2026-02-15` | 連続データ | `2026-03-15, 2026-04-15 …`(日が同じなら月単位) |
| `月` / `Mon` / `1月` / `Jan` | 連続データ | `火, 水 …` / `Tue, Wed …` / `2月, 3月 …`(一周する) |
| `LOT-001` | 連続データ | `LOT-002, LOT-003 …`(0 埋めの桁数を保つ) |
| `切削, 研磨, 検査` | コピー | — |
| 空のセルを含む値 | コピー | —(空のセルから引くと埋める範囲を空にする) |

上 / 左へ引いたときは逆向きに続きます(`1, 2, 3` を上へ引くと `0, -1 …`。元の値が 1 つなら 1 ずつ戻り、`2026-11-02` の上は `2026-11-01`)。

## 細かな動き

- **飛ばすもの**: ラベル行 / グループ行(位置にも数えない)、行ドラッグ / 展開トグル / 自動グループ列の合成列、合計行。フィルター / ソート中は表示されている順に埋め、隠れた行には書きません。表の末尾より先へ行は増やしません。
- **書き込み**: 貼り付けと同じく、編集できないセル(`readOnly` / `editable: false` / `canEditCell`)は飛ばします。clientSide は `onRowsChange` に 1 回で渡し、undo / redo の対象です。値は型を保って書きます。
- **埋めたあとのボタン**: 選択を変える・セルの値が外から変わる・列が変わる・ソート / フィルター / グループの開閉が変わる・編集を始めると消えます。列ごとに埋め方が混ざるときに「連続データ」を選ぶと、すべての列を連続データにします(続き方の無い値はコピーのまま)。連続データにできる値が無いときは「連続データ」を選べません。
- **ダブルクリック**: ハンドルの見えている四角をダブルクリックします。埋める列にすでに値があるセル、ラベル行 / グループ行、未読み込みの行の手前で止まり、既存の値は上書きしません。
- **serverSide**: `dataSource.updateRows` で書き戻します(楽観更新・失敗時のロールバックは編集と同じ)。読み込まれていない行には書かず、元の範囲に読み込まれていない行がある列 / 行は埋めません。undo / redo はありません。ボタンでの選び直しはそのときの行の上に書くため、`validate` の reject で選び直しでは書かないセルには最初に埋めた値が残ります。
- **キーボード**: ハンドルはポインタ操作の部品です(支援技術からは隠しています)。キーボードではコピー / 貼り付けで同じことができます。ボタンのメニューは ↑ / ↓ で移動、`Escape` / `Tab` で閉じます。

## 見た目を変える

| 対象 | クラス / CSS 変数 |
| --- | --- |
| ハンドル | `.ssg-fill-handle`(色は `--ssg-accent`、縁取りは `--ssg-fill-handle-ring`) |
| 埋める範囲の点線 | `.ssg-fill-preview`(色は `--ssg-fill-line`。既定は文字色) |
| ドラッグ中のルート | `.ssg-root--filling` |
| 埋めたあとのボタン / メニュー | `.ssg-fill-options` / `.ssg-menu-panel.ssg-fill-menu` |
| 値のツールチップ | `.ssg-tooltip.ssg-fill-tooltip` |

詳しい仕様は [API リファレンスの「フィルハンドル」節](/docs/api/props#フィルハンドルfillhandle)を参照してください。
