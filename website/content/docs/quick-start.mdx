## 最小の例

`rows` と `onRowsChange` を渡すと、グリッドはコントロールドコンポーネントとして動作します。列には最低限 `key` と `width` が必要です。

```tsx
import { useState } from 'react'
import { SpreadsheetGrid, type GridColumn } from '@ishibashi0112/spreadsheet-grid'
import '@ishibashi0112/spreadsheet-grid/style.css'

type Row = { id: number; name: string; qty: number }

const columns: GridColumn<Row>[] = [
  { key: 'name', title: 'Name', width: 200, editable: true, filterType: 'text' },
  { key: 'qty',  title: 'Qty',  width: 120, editable: true, filterType: 'number' },
]

export function Example() {
  const [rows, setRows] = useState<Row[]>([
    { id: 1, name: 'Apple',  qty: 3 },
    { id: 2, name: 'Banana', qty: 5 },
  ])

  return (
    <SpreadsheetGrid
      rows={rows}
      columns={columns}
      onRowsChange={setRows}
      rowKeyGetter={(row) => row.id}
    />
  )
}
```

## 動作イメージ

- セルを**ダブルクリック**(または F2 / 直接タイピング)で編集開始
- ドラッグまたは Shift + 矢印キーで**範囲選択**、`Ctrl/Cmd+C` / `Ctrl/Cmd+V` でコピー & ペースト
- ヘッダーのメニューから**ソート / フィルター**
- `Ctrl/Cmd+Z` で **undo**、`Ctrl/Cmd+Shift+Z` で **redo**

## Next.js で使う場合

グリッドはフックを使うクライアントコンポーネントです。App Router では `'use client'` を付けたコンポーネントから利用してください。

```tsx
'use client'

import { SpreadsheetGrid } from '@ishibashi0112/spreadsheet-grid'
import '@ishibashi0112/spreadsheet-grid/style.css'
```

関数(`valueFormatter` / `renderCell` / `validate` / `getValue` など)を含む列定義は、`'use client'` のファイルに置きます。サーバーコンポーネントで作ってグリッドへ渡すと、関数はクライアントへ渡せないためページがエラー(500)になります。行のデータ(関数を含まない値)はサーバーで作って props で渡せます。

```tsx
// app/projects/columns.tsx
'use client'

import type { GridColumn } from '@ishibashi0112/spreadsheet-grid'
import type { Project } from './types'

export const columns: GridColumn<Project>[] = [
  { key: 'budget', title: '予算', valueFormatter: ({ value }) => `${Number(value).toLocaleString()} 円` },
]
```

サーバーレンダリング(SSR / SSG)でもエラーや警告なく描けますが、サーバーで描く HTML は表の骨組みです: 行番号と固定した列(`pinned`)のセルだけで、固定していない列(横の仮想化の対象)はハイドレーションの後に描きます(固定列の無い表は、ハイドレーションまで行番号だけの表です)。JavaScript が動かない環境では表の中身は出ません。`theme="auto"` の場合、サーバーでは light として描画され、ハイドレーション後にクライアントの配色設定へ追従します。
