**S9-01 低 / 不具合(開発時だけ)/ Solid だけ / 前の点検では試していない**
- **題名**: custom エディタの部品の本体で `ctx.value` や `ctx.row` を読むと、開発時に STRICT_READ_UNTRACKED が出る。
- **再現手順**: `editor: { type: 'custom', render: (ctx) => <Ed ctx={ctx} /> }` で、`Ed` の本体に `const start = ctx.value` と書いて編集を始める。
- **期待**: 何も出ない。API_REFERENCE では `value` は「編集開始時の生値」という固定の値として書かれています。
- **実際**: 「[STRICT_READ_UNTRACKED] Reactive value read directly in <…> will not update.」が出ます。
  - 回数は value で 1 回、row で 1 回、initialText で 0 回でした。React 版では出ません。
- **回避策**: `untrack(() => ctx.value)` で包むか、`ctx.initialText` を使う。
- **関係**: 既知の S6-22(展開行の ctx)と同じ種類ですが、custom エディタという別の場所で出ます。
- **証拠**: 最小再現が `P/S9/app/src/min-ctx.tsx` と `P/S9/e2e/min-ctx.cjs` です。
- **確度**: 確実。

- `getVisibleRowRange()` は overscan を含みます(ドキュメントでは「描画中」)。見えている範囲を取る API が別にあるとありがたいです。

## 6. 要望
- グリッドの中で列を並べ替える・固定する・非表示にする操作の後も、アクティブセルと選択がその列に付いていくようにしてほしいです(S12-01)。
- Ctrl+Home で中央の横スクロールも先頭へ戻してほしいです。
- Solid 版で、セルごとの外の状態を安く読むための部品やレシピがほしいです。
