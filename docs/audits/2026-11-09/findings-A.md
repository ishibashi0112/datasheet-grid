## 3. 所見

### A-01 年の無い日付を貼り付けると 2001 年として保存される

- 重要度: **高** / 種類: 不具合

**再現手順**
1. date エディタの列に、TSV の「11/2」を Ctrl+V で貼り付けます(`A/app/min/min.tsx` と `A/pw/m01-min.js`)。

**期待**
- ドキュメントには「年が 4 桁でない文字列は読めない(生のまま残す)」とあります。生のまま残るか、検査の印が付くはずです。

**実際**
| 貼り付けた文字列 | 保存された値 |
| --- | --- |
| 「11/2」 | `"2001-11-02"` |
| 「1/15」 | 2001-01-15 |
| 「12/31」 | 2001-12-31 |
| 「Nov 1」 | 2001-11-01 |
| 「1/2/3」 | 2003-01-02(米国式の解釈) |
| 「2026/2/30」 | 2026-03-02(繰り上げ) |

- 印は付かず、見た目は正しい日付なので気づけません。日本の Excel では「11/1」の書式はよくあります。

**証拠**
- 原因は core の `dist/logic/editorValues.js` の日付パーサです。`^\d{4}-\d{2}-\d{2}` に合わないと `new Date(文字列)` に任せ、年が 1000〜9999 なら受け入れます。
- Chrome の `new Date('11/2')` は 2001 年になります。

**回避策**: 列に自前の `parseClipboardValue` を書く。

- dev / 本番: 両方 / 確度: 確実

### A-03 値と表示名が別の select 列は、表示・貼り付け・全体フィルターの扱いがそろわない

- 重要度: 中 / 種類: 使いにくさ・ドキュメント

**再現手順**
1. `editor: { type: 'select', options: [{ value: 'transport', label: '交通費' }, …] }` だけで列を書きます。

**実際**
- セルにはコード(`transport`)が出ます。表示名を出すには `valueFormatter` が要りますが、ドキュメントの select の説明にその記述がありません(`A/shots/01-initial.png`)。
- `valueFormatter` を足すと表示は「交通費」になります。しかし、Excel から表示名の「交通費」を貼り付けると、値としては文字列「交通費」がそのまま入ります(生のまま入るのはドキュメントどおり)。
  - 見た目は他の行と同じで印も出ないので、気づけません。
  - そのため set フィルター・CSV・データの中身がそろわなくなります。
- コピーと CSV は、`formatClipboardValue` を書かないとコードになります。仕様どおりですが、`valueFormatter` とは別に書く必要があります。
- 全体フィルターは生の値だけを見ます。「交通費」「提出済み」「43,340」では 0 件になります。一方、検索(Ctrl+F)は表示の文字列で探すので、扱いが食い違います。

**回避策**
- `valueFormatter` + `formatClipboardValue` + `parseClipboardValue`(表示名をコードに戻す)の 3 つを書く(確認済み。`App.tsx` の `selectClipboard`)。
- 全体フィルターだけは、データに表示名を持たせる以外に手がありません。

**証拠**
- `A/pw/m01-min.js` / `A/pw/t06b-form.js` / `A/pw/t08-select-csv.js` / `A/shots/06-global-filter.png`。
- `A/expenses.csv` は回避策を入れる前に出力したもので、区分がコードになっています。

- dev / 本番: 両方 / 確度: 確実

### A-04 Tailwind v4 と一緒に使うと、ダークで列フィルターの入力欄の文字が黒くて読めない

- 重要度: 中 / 種類: 不具合

**再現手順**(`A/app/min/dark.tsx?css=layer` または `css=plain`、`A/pw/m02-dark.js`)
1. `theme="dark"` にします。
2. set / text / number / dateSet のどれかのフィルターを開き、入力欄に文字を打ちます。

**期待**
- ドキュメントでは Tailwind v4 は「そのまま動きます」とあり、文字はパネルの文字色で出るはずです。

**実際**
- `.ssg-filter-input` の color は `rgb(0,0,0)`、背景は `rgb(37,38,43)` で、ほとんど見えません。
- Tailwind を入れないと白で出ます。

**回避策**
- `.ssg-filter-popover { color: var(--ssg-panel-text-strong) }` を足すと `rgb(241,243,245)` になりました(`A/pw/m02b-dark-workaround.js`)。
