## 1. 進め方と前提

- 対象: npm の公開版 1.0.0(`@ishibashi0112/spreadsheet-grid` と `-core`。main の df83c53)。
- 12 本のアプリを、リポジトリのソースを見ない担当(サブエージェント)が、npm の公開版と利用者が見られる資料(同梱の README / API_REFERENCE.md / Skill、ドキュメントサイトの `website/content/docs` の写し、CHANGELOG)だけで作った。担当への指示は `audit/dogfood/2026-11-09/BRIEF.md`。

## 2. ユーザーの判断(2026-11-09)

- 「あなたの推奨案で全て修正してほしい」(09:48Z)。報告の「対応」の推奨どおりに全件を進める。決めてほしいことの 4 つも推奨どおり:
  1. AP-03: 見出しのチェックボックスはフィルター中なら見えている行だけを選ぶ(1.0.1)。ハンドルの `selectAllRows()` は変えない(「全行を選択」と書いてある)。
  2. AP-07: ポップアップを描く場所を選ぶ prop を足し、モーダル(`<dialog>` と `aria-modal`)の中なら自動でその中へ描く(1.1.0)。
  3. AP-08: 既定は変えずに選べる形で足す(1.1.0)。グループの見出しに列の書式 / 全体フィルターを画面の文字でも当てる / select の表示名を貼り付けで値へ戻す。
  4. ピン留め行: 1.0.1 を出した後、1.1.0 で「表とは別のデータの行」の形(`pinnedTopRows` / `pinnedBottomRows` のような別の配列)から作る。
- 見送り(意図して直さない): K-09(そろえると壊す変更)、F-08(要望が出てから)、F-07(区分ごとの小計は別の機能)。L-08 の既定の色の変更も壊す変更なので、コントラストの高いトークンの値を文書で案内する。
- 版: 1.0.1 = 高の AP-01 / 02 / 03 / 04 / 05 / 06 + 中の「1.0.1」 + 文書の修正。1.0.2 = 低の「1.0.2」+ 確かめ直す 4 件。1.1.0 = 機能の追加 + ピン留め行。

## 4. ピン留め行について分かったこと
